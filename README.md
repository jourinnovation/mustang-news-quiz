# mustang-news-quiz
This quiz was originally created by Leila Toati to help Mustang News increase its local readership on its website by gamifying news. With eight to 10 questions about the local stories published by the student newspaper, the quiz was released on the homepage of mustangnews.net every Sunday for months. 
This quiz was also a part of the Reynolds Journalism Institute Student Innovation Competition, where two Cal Poly students were finalists in 2025. 
To edit and make your own, edit the script.js file to add your own questions, signifying the correct answer with true.
